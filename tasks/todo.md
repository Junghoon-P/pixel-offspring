## 결정 및 검토 기록
- 기존 앱 없는 신규 프로젝트. 기본 의존성은 시작 프롬프트에서 승인됨.
- TanStack Query 검토: 서버 캐시 공유 필요가 작아 추가 도입 없이 조회 훅과 명시적 재조회 사용.
- 제안값: 질문/점수 v1, 닉네임 12 grapheme, 초대 30일, 캐릭터/세션 90일, 목록 20개, 본문 8KiB.
- 인터페이스: 엔진→저장→화면/PNG는 동일 버전 레시피. 공개 응답에서 내부 traits/owner 제외.
- UI 레이아웃은 개발 초안이며 승인된 화면 디자인으로 표시하지 않는다.
- 실제 기기/클라우드 계정 접근 없는 항목은 미검증. 운영 배포하지 않는다.
- 사용자 승인: 크림 배경·자주 글자·민트/코랄 버튼, 모바일 한 열 초안 진행.
- 엔진 4개 테스트(64패턴, 4096쌍 반전/유전 검증) RED→GREEN, 공유 2개 RED→GREEN.
- API 최초 테스트는 샌드박스 접속 오류로 기능 RED 증거가 아님. 실제 D1 연결 후 2개 통합 테스트 통과. 화면 최초 테스트도 브라우저 미설치로 기능 RED 증거가 아님. 이를 TDD 성공으로 과장하지 않음.
- Chrome 두 브라우저 E2E 2개 통과: 질문/초안/초대/결과/다운로드/삭제.
- Ruling: 쓰기·세션 발급 제한을 30회/분으로 조정. 20개 동시 신규 조합 검증과 중복 요청 허용을 위한 초기 burst 설정. 일반 읽기는 60회/분. 전역 비용 상한이 아님.
- 실제 시각 확인에서 시트 행 경계 불균일 발견: 0/420/755/1086px 경계로 정리, 달팽이 이불 파츠 별도 호환 변형.
- QA에서 머리 슬롯 충돌 회귀 테스트를 추가하고 실패 확인 후 불꽃/새싹 중 하나만 물려받도록 수정. 호환 불가 파츠는 유전 내역에도 기록하지 않음.
