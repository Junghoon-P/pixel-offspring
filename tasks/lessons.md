# 작업 교훈

- 캐릭터 파츠는 생성 원본만 보고 승인하지 않는다. 실제 64px 렌더러의 2배/3배 크기에서 눈의 식별성, 얼굴 가림, 부모·자식 합성을 확인한다.
- 표정의 가로세로 비율을 보존하고, 장식은 몸통별 부착 좌표와 얼굴 안전 영역을 둔다. 얼굴 위에 덮는 범용 이불과 사각형으로 잘라낸 변형은 피한다.
- 시각 개선도 저장된 결과를 바꾸지 않도록 에셋 버전을 분리하고 구버전 렌더링을 회귀 검사한다.
- 이불은 얼굴을 가리지 않는 것만으로 합격이 아니다. 실제로 몸을 덮는 천의 면적·주름·앞뒤 관계가 보여야 한다. 테두리 형태의 구멍 뚫린 이불을 ‘덮었다’고 판단하지 않는다.
- 4096개 조합의 논리 테스트와 아트 품질 승인을 구분한다. 질문에서 잘 나오지 않는 파츠 조합도 별도 전체 행렬로 검수한다.

- 배포 플랫폼을 구현 전에 명시하고 사용자의 운영 환경과 맞춘다. 로컬 기능 완료와 실제 호스팅·DB 연결 완료를 구분하며 플랫폼 전용 런타임·DB 의존성을 함께 설명한다.
- 사용자가 열어둔 Chrome을 지정하면 해당 창과 프로필을 우선 확인한다. 확장 도구에 보이는 탭만으로 다른 프로필의 로그인 상태나 계정 접근 불가를 단정하지 않는다.
- 얼굴 합성은 64px 경계 안에 들어온다는 검사만으로 승인하지 않는다. 비대칭 몸통의 머리 방향·날개·뿔 등 실제 조형을 기준으로 얼굴 안전 영역을 검수하고 큰 PNG에서도 확인한다.
- 캐릭터 한 종의 위치만 고치는 것으로 전체 조합 품질 문제를 해결했다고 판단하지 않는다. 여섯 몸통의 얼굴 방향·가림·부착점을 함께 검수하고, 조합은 양쪽 부모의 실루엣 기여와 결과 다양성까지 평가한다.
- 캐릭터 다양성을 색·표정·장식 수로 대신하지 않는다. 사용자가 코믹한 기믹을 원하면 종별 실루엣, 행동, 소품의 관계와 혼합 시 생기는 상황까지 설계한다.
- 16유형을 서로 다른 캐릭터로 요구한 작업에서 같은 몸통의 표정/장식 변형을 별개 캐릭터로 세지 않는다. 유형별 전용 실루엣·행동·소품을 각각 마련하고 몸통 ID 중복이 없는지 테스트한다.
- 사용자가 밈 스타일을 요청하면 둥글고 귀여운 소품만 늘리지 않는다. 눈꺼풀·입매·얼굴 비율·몸짓 자체의 우스꽝스러움을 구현하고, 기존 유형을 유지할지 후보를 확장할지 명시한다.
- 혼합 캐릭터는 신체 기관·얼굴·다리의 합성을 늘리면 불쾌감을 줄 수 있다. 사용자 선호에 따라 한 종의 얼굴과 몸을 온전히 유지하고 다른 부모는 분명히 벗을 수 있는 옷·모자·소품으로 표현한다. 코믹함은 기형적 구조보다 표정·행동에서 만든다.
