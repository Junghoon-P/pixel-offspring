# 캐릭터 성향 v3 — 콘텐츠·구현 기준

2026-10-20. 사용자 승인 방향: MBTI형 성향 테스트 → 개인 풀이 → 궁합 → 합성 캐릭터 → 레전드 도감.
사용자 진행 지시에 따라 24문항·개인 풀이·상황별 궁합·레전드4종의 첫 버전을 구현했다. 아래 샘플은 편집 방향이며 실제 문장은 점수별 규칙으로 구성한다.

## 제품 원칙

- MBTI처럼 이해하기 쉬운 자체16유형을 사용한다. 현재 모험·활동·즉흥·표현을 E/I·S/N·T/F·J/P로 바꾸어 부르지 않는다. 정식 MBTI 검사라는 표현을 쓰지 않는다.
- 현재16기본 캐릭터와4특수 캐릭터를 유지한다. 관계2축은 기본 캐릭터 수를 늘리지 않고 개인·궁합 풀이를 확장한다.
- 결과는 오락 콘텐츠. 성향에 우열을 두지 않으며 궁합을 실제 관계 성공 확률로 표시하지 않는다.
- 같은 입력·규칙 버전은 같은 결과. 새로고침으로 레전드 결과를 추첨하지 않는다.
- 한쪽 외형으로 대체하지 않는 현재 합성 규칙과 기존 저장 결과 스냅샷을 유지한다.
- 초기에는 검수한 문장과 결정적 규칙을 사용한다. 실시간 AI 생성과 사주 계산은 이번 범위에 넣지 않는다.

## 설문24문항

응답: A에 매우 가까움 / A에 조금 가까움 / 둘 다 비슷함 / B에 조금 가까움 / B에 매우 가까움.
UI에는 점수와 측정 축을 표시하지 않는다. 아래의 축별 배치는 검토용이며 실제 문항은 여섯 축을 번갈아 배치한다.

응답이 상황에 따라 달라지는 사용자를 위해 중립 선택을 허용한다. '모르겠음'을 한쪽 성향으로 처리하지 않는다.
점수: 축별 문항의 방향에 맞춰 -2,-1,0,1,2로 변환하고 합계/8로 정규화한다. 부호와 강도를 분리한다.
0점은 균형 성향으로 풀이한다. 기본16유형의 외형 선택에 필요한 동점 처리 규칙은 구현 전 확정한다. 문항 순서나 부모 ID로 성격을 정하지 않는다.

## 개인 결과 샘플3개

아래 예시는 해당 캐릭터의 모든 사용자에게 고정되는 문구가 아니다. 명시한 세부 성향을 만족할 때의 샘플이다.

### 고양이 — 약속은 미리, 마음은 천천히
가정: 익숙함·느긋함·계획·조용한 표현, 숙고 후 논의·공감 우선.

한 줄: 편한 자리를 찾으면 오래 머물고, 편한 사람을 만나면 더 오래 마음을 줘요.

풀이: 갑자기 큰 즐거움이 생기는 것보다, 기대했던 하루가 편안하게 흘러갈 때 만족해요. 좋아하는 사람을 자주 챙겨도 그 이유를 길게 설명하지는 않아요. 반응이 작다고 관심까지 작은 건 아니에요.
장점: 사소한 취향을 기억하고 꾸준히 챙겨요.
오해받는 점: 생각을 정리하는 시간이 무관심처럼 보일 수 있어요.
지칠 때: 일정과 대화가 한꺼번에 몰리면 혼자 숨 돌릴 시간이 필요해요.
친해지는 법: 갑작스럽게 끌고 나가기보다 미리 시간을 정해 주세요. 말할 준비가 됐을 때 기다려주는 사람이 편해요.

### 라쿤 — 준비한 모험은 두 배로 신나
가정: 탐색·활발함·계획·적극적 표현, 바로 논의·해결 제안.

한 줄: 새로운 걸 해보고 싶어서 준비하고, 재미있어서 친구까지 데려가요.

풀이: 처음 보는 장소나 경험에 마음이 움직여요. 그렇다고 무작정 출발하기보다는 갈 길과 준비물을 챙길 때 더 신나요. 함께할 사람이 있다면 좋아하는 이유와 다음 계획을 자연스럽게 나누는 편이에요.
장점: 생각만 하던 일을 실제 일정으로 만들어요.
오해받는 점: 도와주려는 제안이 상대에게는 재촉처럼 들릴 수 있어요.
지칠 때: 정성껏 준비한 계획이 이유 없이 흐지부지되면 힘이 빠져요.
친해지는 법: 새로운 제안에 관심을 보여주세요. 해결책보다 공감이 필요한 날에는 먼저 말해주면 좋아요.

### 우파루파 — 재미있는 쪽으로 일단 출발
가정: 탐색·활발함·즉흥·적극적 표현, 바로 논의·공감 우선.

한 줄: 계획에 없던 순간을 발견하면 같이 웃을 사람부터 찾아요.

풀이: 상황에 맞춰 방향을 바꾸는 일이 크게 부담스럽지 않아요. 좋은 것을 발견하면 혼자 간직하기보다 바로 나누고 싶어져요. 이야기를 들을 때도 다음 행동을 정하기 전에 상대의 기분에 함께 반응하는 편이에요.
장점: 낯선 상황에서도 즐길 거리를 찾아요.
오해받는 점: 가벼운 제안이 이미 결정된 약속처럼 전달될 수 있어요.
지칠 때: 작은 행동까지 미리 정해져 있으면 답답해질 수 있어요.
친해지는 법: 꼭 지켜야 할 약속만 분명히 하고, 나머지는 함께 골라보세요.

## 궁합 결과 샘플3개

### 고양이 × 라쿤 — 계획은 찰떡, 속도는 조율
잘 맞음: 둘 다 약속이 정해져 있으면 편해요. 함께하는 일의 준비가 비교적 수월해요.
보완: 라쿤이 새로운 선택지를 제안하고, 고양이가 편하게 머물 자리를 찾아요.
마찰: 라쿤은 바로 풀고 싶지만 고양이는 생각할 시간이 필요할 수 있어요.
팁: '지금 결론 내지 말고 저녁에 다시 이야기하자'처럼 돌아올 시간을 정해두세요.
유전: 고양이의 느긋한 리듬 + 라쿤의 탐색 욕구.
능력: 준비물은 완벽하지만 쉬는 시간도 빠뜨리지 않는 원정대.

### 우파루파 × 우파루파 — 출발은 1초, 집합은 미정
잘 맞음: 새로 해보자는 제안에 쉽게 호응하고, 즐거움을 바로 나눠요.
보완: 어느 한쪽이 분위기를 전부 이끌지 않아도 이야기가 이어져요.
마찰: 둘 다 즉흥적이면 재미있는 제안만 늘고 시간·장소가 빠질 수 있어요.
팁: 출발 시간과 만날 장소만 먼저 정하고 나머지는 비워두세요.
유전: 양쪽의 탐색·즉흥 성향이 강화된 두 머리 캐릭터.
능력: 계획 없이 출발해 계획에 없던 추억을 가져오기.

### 숙고·공감형 × 바로논의·해결형 — 마음은 같은데 사용 설명서가 다름
잘 맞음: 서로에게 도움이 되고 싶다는 마음이 있어요.
보완: 한쪽은 마음을 살피고 다른 쪽은 다음 행동을 찾는 역할을 할 수 있어요.
마찰: '같이 방법을 찾자'가 '그만 속상해해'로 들릴 수 있고, 잠깐의 침묵이 대화 거절처럼 보일 수 있어요.
팁: '지금은 들어주면 좋겠어' 또는 '방법을 같이 찾아줘'부터 말해보세요. 혼자 생각할 때는 다시 이야기할 시간을 알려주세요.
주의: 이 예시는 관계2축만으로 생성하는 부분 풀이이며 활동·탐색 궁합을 추정하지 않는다.

## 레전드 조합 샘플2개

### 이불 밖 원정대
조건 제안: 두 사람 모두 탐색 점수 >=0.5, 한쪽 활동 >=0.5·다른 쪽 <=-0.5. 양쪽 순서 무관.
발견 문구: 가보고 싶은 곳은 같은데, 출발할 때의 에너지가 정반대였어요. 한 명은 길을 찾고 한 명은 쉴 곳을 챙기는 레전드 조합이 태어났어요.
외형 방향: 두 부모의 외형을 유지하면서 이불·탐험 가방 등 전용 공통 소품을 추가. 기존 코스튬과 충돌하면 전용 합성 에셋 필요.
도감 힌트: 같은 곳을 꿈꾸는, 다른 속도의 친구를 만나보세요.

### 무계획 대참사
조건 제안: 두 사람 모두 즉흥 >=0.75 및 탐색 >=0.5. 양쪽 순서 무관.
발견 문구: 둘 다 '일단 가보자'고 말했고, 아무도 도착지를 묻지 않았어요. 길은 잃어도 이야깃거리는 잃지 않는 레전드 조합이에요.
외형 방향: 두 부모가 뒤엉킨 실루엣과 거꾸로 든 지도. 몸·얼굴의 부모별 기여 유지.
도감 힌트: 준비보다 출발이 빠른 두 친구가 만나면?

레전드는 좋은 궁합의 보상이 아니다. 서로 다른 레전드 조건이 동시에 맞으면 고정 우선순위로 대표 외형 하나를 선택하고, 만족한 조건은 모두 기록한다. 우선순위와 조건 강도는 분포 시뮬레이션 후 확정한다. 시뮬레이션 입력 분포와 실제 사용자 발생률은 구분한다.

## 개발 단계와 검토 기준

1. 문항·말투·유형 동점 정책 확정. 전형적인 사용자3명의 개인→궁합→레전드 흐름을 맞춰본다.
2. 설문v3와 점수 체계. 기존 survey.ts 패턴을 재사용하고 길이 제한에 맞춰 문항 데이터만 분리한다. 원본 답변 대신 정규화 성향·필요한 근거 태그만 저장한다.
3. 개인 풀이. 양극·중립·강도 경계에서 문장이 모순되지 않는지 테스트한다.
4. 궁합. 양쪽 점수를 보존하고 상황별 공통점·보완점·마찰·팁을 산출한다. 조합 순서가 바뀌어도 결과는 같아야 한다.

## 첫 구현의 범위와 검토 결과

- 기본4축 동점은 기존 비양수 방향으로 외형을 정하고 풀이에는 균형 성향을 명시한다.
- 레전드4종은 수호자 → 원정대 → 동맹 → 대참사 순서로 대표 외형을 선택한다. 동시에 맞는 조건은 모두 저장하고 도감에 표시한다.
- 레전드 외형은 두 부모의 합성·기존 코스튬에 잎·불꽃·이불·반짝임 장식을 추가한다. 전용 신규 일러스트는 아직 제작하지 않았다. 미발견 도감은 물음표와 조건 힌트를 표시한다.
- 독립·균등한5선택 답변을 가정한100,000쌍 시뮬레이션: 대표 수호자4, 원정대31, 동맹1, 대참사0. 실제 답변은 서로 독립적이지 않으므로 실제 출현률로 표시하지 않는다. 모든 조건의 도달 가능성은 별도 경계 테스트로 확인했다. 실제 분포 관찰 후 임계값 조정이 후속 과제다.
- 최종 리뷰1회에서 다중 조건 도감 누락1건을 발견해 회귀 테스트 후 수정했다. 기존 저장 결과는 재계산하지 않는다.
